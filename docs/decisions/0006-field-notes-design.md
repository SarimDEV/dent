# 0006. Visual direction: Field Notes

Status: accepted (2026-10-11) · Spec: [design.md](../design.md)

## Decision

Warm paper (light) and warm carbon (dark), fine static grain, ink type (Geist, Geist Mono, Instrument Serif), status as dithered pixel squares with a distinct pattern per status. ASCII trees for tool calls as an accent.

## Why

Best for long reading, distinctive in the category, and cheap to draw (no live blur).

## Consequences

Palette tokens in docs/design.md are the only colours renderers use. Mockups in docs/design/mockups/ are the reference. Fixes before building are listed in docs/design.md.
