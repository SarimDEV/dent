# Moves, updates and settings across machines: mockups

For choosing before building. Each page has options where there's a real choice.

- `move.png` (`move.html`): starting a move from the header (A) or the machine chip under the reply box (B), then the shared states: moving, stopped partway, and what's left on the old machine.
- `machines.png` (`machines.html`): updates in Settings › Machines, with a version on every row (A) or one card when there's an update (B), and settings across machines (Mixed, not saved yet, per-machine settings).

The pages use `dent.css` with the app's fonts and palette; open them in a browser to look closer.
