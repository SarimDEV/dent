# Code of conduct

dent follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good faith, and keep discussion about the work. Harassment and personal attacks aren't welcome in issues, pull requests or anywhere else the project lives.

To report a problem, contact the maintainer, [@SarimDEV](https://github.com/SarimDEV), privately. Reports are kept confidential.
